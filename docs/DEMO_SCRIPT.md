# Helpy Demo Script

Suggested duration: 3–5 minutes.

## 1. Landing page

Show the hero, How it works, and pricing sections.

Voiceover:

> Helpy turns company documentation into an AI assistant. A team can upload
> its knowledge, test answers inside the product, and embed the same assistant
> on a website with one script.

## 2. Create a workspace

1. Click `Get started`.
2. Create an account with a demo email and password.
3. Show the dashboard and onboarding checklist.

## 3. Add knowledge

1. Open `Knowledge`.
2. Add text knowledge titled `Returns FAQ`.
3. Use this content:

```text
Customers can return unused items within 30 days of delivery.
Refunds are issued to the original payment method within five business days.
Standard delivery takes three to five business days.
```

4. Show the `ready` status.

## 4. Test the assistant

1. Open `Playground`.
2. Ask: `How long do customers have to return an item?`
3. Show the answer and `Returns FAQ` as the source.
4. Ask a question that is not in the knowledge base and show the grounded response.

## 5. Embed the widget

1. Open `Embed`.
2. Change the assistant name and accent color.
3. Show the live preview.
4. Copy the generated snippet.
5. Open `/demo-site` and show the page where the snippet can be installed.

## 6. Pricing and gates

1. Open `Billing`.
2. Show Starter: 3 sources and 50 messages.
3. Click `Switch to Growth`.
4. Show the mock confirmation and updated plan status.

Closing line:

> The MVP keeps the scope focused: knowledge ingestion, grounded answers,
> embeddable delivery, and a clear path from the free plan to Growth.
